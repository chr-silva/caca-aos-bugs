# 🐛 Caça aos Bugs! — Calourada DS

O **Caça aos Bugs!** é um jogo web interativo desenvolvido especialmente para a recepção dos calouros (Calourada) do curso de Desenvolvimento de Sistemas (DS). O objetivo é testar os reflexos dos participantes capturando vírus e bugs enquanto evitam arquivos do sistema e escudos de proteção.

---

## 🚀 Funcionalidades

- 🎮 **Modo Solo:** Jogabilidade rápida com contagem regressiva de tempo e pontuação.
- 🌐 **Modo Multiplayer (Salas/Lobbies):** Criação e entrada em salas via código para competir em tempo real com outros calouros.
- 🏆 **Ranking em Tempo Real:** Tabela com os Top 5 Caçadores integrada via Firebase.
- 🔊 **Trilha Sonora e Efeitos:** Músicas de fundo e controle de áudio (Mute/Unmute).
- 📜 **Créditos Interativos:** Seção estilizada destacando o desenvolvedor, organizadores e testadores Alpha/Beta.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES6 Modules)
- **Framework UI:** [Bootstrap 5](https://getbootstrap.com/) & Bootstrap Icons
- **Backend & Database:** [Firebase](https://firebase.google.com/) (Realtime Database / Firestore)

---

## 🕹️ Como Jogar

1. **Bug (`+100 pts`):** Elimine os erros simples do sistema!
2. **Vírus (`+250 pts`):** Ameças de alto valor, clique rápido!
3. **Arquivo (`-50 pts`):** Atenção! Não apague arquivos importantes.
4. **Escudo (`-40 pts`):** Cuidado para não danificar a proteção do sistema.
